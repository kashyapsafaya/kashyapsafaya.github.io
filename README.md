# kashyapsafaya.github.io

Personal portfolio site for Kashyap Safaya. Pure HTML/CSS — no build step.

## Local preview
```sh
python3 -m http.server 8000
# open http://localhost:8000
```

## Deploy
GitHub Pages is enabled automatically when this repo is named `kashyapsafaya.github.io` and pushed to the `main` branch. Site is then live at https://kashyapsafaya.github.io within ~1 minute.
